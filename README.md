# Google Drive 批量分类上传 & 7z自动加密 & 谷歌表格归档 & 批量删除工具

一款专为 **本地文件按规则分文件夹批量加密上传到 Google Drive、同步生成层级结构 Google Sheets / Excel 表格、以及服务结束后批量删除云端链接** 打造的桌面可视化工具。

---

## ✨ 核心功能

### 📤 页面一：批量分类上传 & 7z自动加密 & 谷歌表格归档
1. **定量分文件夹上传（多的不传、少的不重复、日志详细说明）**
   - 自由设置 **需要创建的云端文件夹数 ($M$)** 与 **每个文件夹上传的文件数 ($N$)**，自动计算计划总量 $M \times N$。
   - **本地文件多于计划量 ($X > M \times N$)**：严格只取前 $M \times N$ 个文件上传，多余的 $X - M \times N$ 个文件不上传、保留在原目录中，日志明确说明。
   - **本地文件少于计划量 ($X < M \times N$)**：严格遵循**绝不重复上传**原则，仅按实际可用文件唯一上传，并在日志中详细说明差额与各文件夹实际装入数量。
2. **上传前自动 7z 加密开关（强制加密文件名 `-mhe=on` + 手动密码）**
   - 开启后，不论上传什么格式文件，均自动调用 7-Zip 进行 AES-256 加密并强制开启 `-mhe=on`（未输入密码无法看到内部文件名）。
   - 支持 **「每个文件独立加密为单独的 `.7z` 压缩卷上传」** 或 **「将每个子文件夹内的 $N$ 个文件合并加密为 1 个 `.7z` 压缩卷上传」**。
3. **防重复上传：单文件上传成功立即移入「已上传」归档目录**
   - 每当一个本地文件上传成功并开启公开下载权限后，立即移动到源目录下的 `已上传/<对应云端子文件夹名>/` 中，彻底杜绝重复上传。
4. **自动开启公开下载权限 & 按层级写入 Google Sheets 与本地 Excel**
   - 自动对 **云端总文件夹**、**各分类子文件夹**、**每个上传的单个文件** 开启公开读取/下载权限（`anyone` $\rightarrow$ `reader`）。
   - 同时生成两张层级工作表：**「层级分栏总表」**（左到右三级分栏并纵向合并同级文件夹单元格）与 **「树状目录层级表」**（上到下树状缩进展示）。

### 🗑️ 页面二：云端链接批量删除清理（服务结束后一键删链接）
1. **智能识别所有链接格式 & 自动去重**
   - 支持直接粘贴 **单文件直接下载直链**、**单文件在线预览链接**、**总文件夹/子文件夹链接**、**纯云端 ID**，或直接从谷歌表格 / Excel 整列复制粘贴，自动提取 ID 并去重。
   - 支持点击 **「📊 从本地 Excel 层级报表导入链接」** 一键提取报表中生成的链接。
2. **三种清理模式可选**
   - 🔥 **彻底永久删除**：从谷歌云盘直接抹除，立即释放云盘空间。
   - ♻️ **移入云盘回收站**：外链停止下载，30 天内可在云盘回收站还原。
   - 🔒 **仅关闭公开下载权限**：文件保留在云盘内，但分享下载直链立即失效。

## 🤖 上传 GitHub 自动打包生成 `.exe` 说明

本项目已内置 GitHub Actions 自动打包工作流（`.github/workflows/build_exe.yml`）：

1. 在 GitHub 上新建一个仓库（建议设为 Private 私有仓库或 Public 公开仓库）。
2. 将本项目文件夹内的所有文件上传或 `git push` 到 GitHub 仓库的 `main`（或 `master`）分支。
3. 推送完成后，GitHub 会自动触发 **Actions (`Build Windows EXE`)**：
   - 自动在云端 Windows 环境中安装依赖并内置 7-Zip 引擎，打包生成单文件 **`GDriveBatchTool.exe`**。
   - 您可以在 GitHub 仓库的 **「Actions」 -> 「Build Windows EXE」 -> 底部「Artifacts」** 下载 `GDriveBatchTool-Windows-EXE`，或者直接在仓库右侧的 **「Releases」** 页面下载最新生成的 **`GDriveBatchTool.exe`**！

## 💻 本地直接运行或本地打包 `.exe`

- **直接运行源码**：双击 `启动工具.bat`（或执行 `python main.py`）。
- **本地一键生成 `.exe`**：双击 `build_exe.bat`，打包完成后在 `dist\GDriveBatchTool.exe` 即可拿到独立可执行文件。
